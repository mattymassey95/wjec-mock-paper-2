# GCSE Maths Mock Quiz

A mobile-friendly quiz with 22 questions based on the WJEC GCSE Mathematics & Numeracy Unit 2 (Higher, non-calculator) sample paper.

- Asks for the player's name and age, then shows the questions in a random order
- New numbers on every play, with the same difficulty
- Accepts different ways of typing an answer (fractions, decimals, mixed numbers, any order, rearranged algebra and inequalities)
- Progress bar at the bottom and a cheeky personalised message at the end

## Hosting on GitHub Pages
1. Push `index.html`, `styles.css` and `script.js` to the repository.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, then pick your branch and the `/ (root)` folder.
3. The quiz goes live at `https://<username>.github.io/<repo-name>/`.
